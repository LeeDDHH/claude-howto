# 나의 Claude Code 학습 노트

`claude-howto` 튜토리얼로 공부하며 정리하는 개인 학습 폴더.

## 구조

```text
study/
├── README.md                     # 이 파일 (목차)
└── docs/
    ├── 01-assessment.md          # 실력 평가 결과 & 약점
    ├── 02-learning-path.md       # 학습 경로 (진행 체크리스트)
    ├── 03-practice-projects.md   # 실습 프로젝트
    └── lessons/                  # 주제별 학습 정리
        ├── _template.md          # 새 레슨 노트 템플릿
        └── 01-custom-skills.md   # 커스텀 스킬 만들기 (진행 중)
```

## 사용법

1. 새 주제를 시작하면 `docs/lessons/_template.md`를 복사해 `NN-주제.md`로 만든다.
2. 공부한 내용, 실습 결과, 막힌 점을 레슨 노트에 적는다.
3. 완료 기준을 만족하면 `docs/02-learning-path.md`의 체크박스를 체크한다.
4. 한 Phase를 마치면 `/self-assessment`로 다시 평가하고 `docs/01-assessment.md`에 기록을 추가한다.
